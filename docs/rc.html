Testversie van de firmware

Test version of the firmware

Let op: dit is een testversie. Er kunnen nog fouten in zitten. Installeer hem alleen als je gevraagd bent om te helpen testen. Voor normaal gebruik installeer je de stabiele versie via de gewone installatiepagina.

Note: this is a test version. It may still have bugs. Only install it if you were asked to help test it. For normal use, install the stable version from the regular install page.

  1. Gebruik Chrome of Edge op een laptop of desktop.
  2. Sluit het board aan met een USB-datakabel.
  3. Klik op Install, kies de seriële poort en laat het tabblad open staan.
  4. Vul je wifigegevens in als daar om gevraagd wordt.
  1. Use Chrome or Edge on a laptop or desktop.
  2. Connect the board with a USB data cable.
  3. Press Install, pick the serial port, and keep the tab open.
  4. When asked, enter your Wi-Fi.

Heb je het apparaat in het ESPHome dashboard geadopteerd? Zet dan in de YAML de versie achter de @ in de regel met github://JoooostB/esphome-zehnder-comfoair-rf terug naar de stabiele versie en klik op Install.

Adopted the device in the ESPHome dashboard? In its YAML, set the version after the @ in the line with github://JoooostB/esphome-zehnder-comfoair-rf back to the stable version and press Install.
